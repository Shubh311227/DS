# DS
# Data Structures & Algorithms Practice

A collection of solutions and notes covering core DSA topics, implemented in Java.

## 📂 Contents

### Arrays
Problems involving traversal, searching, sorting, two-pointer techniques, sliding window, and in-place manipulation.

### Strings
Pattern matching, string manipulation, palindrome checks, anagrams, and substring problems.

### Recursion
Base problems building recursive intuition — factorial, Fibonacci, sum of digits, power functions, and tree/array recursion patterns.

### Backtracking
Problems that build and prune a solution space incrementally:
- N-Queens
- Knight's Tour
- Sudoku Solver
- Permutations & Subsets
- Rat in a Maze

### Time & Space Complexity
Notes and examples analyzing:
- Big-O, Big-Θ, and Big-Ω notation
- Best/average/worst case analysis
- Recurrence relations and the Master Theorem
- Space complexity of recursive vs iterative solutions

## 🧠 Notes

Each folder contains:
- The solution file(s) (`.java`)
- Inline comments explaining the approach
- Where relevant, a note on time/space complexity of the solution

## 🚀 How to Run

Each file is self-contained with a `main` method. Compile and run individually:

```bash
javac FileName.java
java FileName
```

## 📌 Purpose

This repo is a personal practice log for strengthening problem-solving skills and preparing for technical interviews, organized by topic for easy review and revision.
